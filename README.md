## 🎯 عن المشروع

**mSec.Nexus** هو مشروع تدريبي عملي لتعلّم أساسيات أمن تطبيقات الويب من خلال بيئة محلية آمنة.

يحتوي المشروع على واجهة Cyber Security بالإضافة إلى مجموعة من الثغرات المتعمدة للتدريب وفهم كيفية اكتشافها ومعالجتها.

### 🧪 التحديات

- SQL Injection
- Command Injection
- Stored XSS
- Reflected XSS
- IDOR
- LFI
- API Data Exposure
